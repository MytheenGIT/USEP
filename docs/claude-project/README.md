# USEP shared Claude Project pack

Version 1.0, 25 Nov 2026. This pack sets up one shared Claude Project for the USEP Engineering Context Layer team, so everyone works from the same instructions, decisions and standards.

Start with `claude-project-setup-guide.md`. It gives the steps in order. The instructions to paste are in `01-project-instructions.md`. The knowledge files are in `knowledge/`, the templates in `templates/`, and the Claude Code file for the repository in `repo/CLAUDE.md`.

The repository copy in `docs/claude-project/` is the source. Changes are made there, through pull requests, and then copied to the Project.

Owner: semantic architect (backup: platform lead). Review: semantic architect and platform lead for every change to the pack.
